1. MAKE HOME AND TODAY THE PRIMARY EXPERIENCE

- open the Home screen

- do not render the full 122-task list visibly behind Home
- preserve task history and preferences
- do not rerun onboarding

HomeTask in the upper-left must continue to open Home from anywhere.

On Home, make Today the most prominent action:

- full-width or otherwise visually dominant
- display the accurate number requiring attention now
- use calm language

Example:

“10 Tasks Need Attention Today”

The count must come from one shared authoritative workload function.

Define “requires attention now” as:

- severely overdue
- overdue
- due today
- unresolved safety tasks
- optionally tasks completed today if they remain visible in Today

Do not count future tasks.

The Home count, Today header, progress indicator, and empty state must all use the same underlying calculation.

Add tests preventing count disagreement.

- Today
